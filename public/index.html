Descripción: Esta es una API para el manejo de productos de una ecommerce La prueba de sus endpoints se puede realizar con POSTMAN. Dichos endpoints se listaran a continuación, nótese que algunos de ellos requieren autorización y otros no.
Metodo Endpoint Autorización Uso
GET "/api/products" No Web / Postman
GET "/api/products/id" No Web / Postman
POST "/api/products" Si Postman
PUT "/api/products/id" Si Postman
DELETE "/api/products/id" Si Postman
POST "/api/login" No Postman
